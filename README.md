# Production

Desktop-приложение для учета производственных сущностей: продукции, операций, материалов, чертежей, инструментов, типов инструментов, цехов и нарядов на работы.

## Назначение проекта

Приложение реализовано как WinForms-интерфейс для базового управления производственными справочниками и связанными сущностями. Основная работа выполняется через `MainForm`, где данные разделены по вкладкам и доступны для добавления, просмотра, редактирования и удаления.

Проект подойдет как учебный пример настольного CRUD-приложения с файловым хранением данных и разделением на доменный слой, слой репозиториев и слой use case.

## Технологии

- `C#`
- `.NET 8` (`net8.0-windows7.0`)
- `Windows Forms`
- `Newtonsoft.Json`
- JSON-файлы как способ хранения данных
- Архитектурное разделение на `Domain` / `Repository` / `Usecase`

## Возможности приложения

- ведение списка продукции;
- ведение списка производственных операций;
- учет инструментов и типов инструментов;
- учет материалов и чертежей;
- ведение справочника цехов;
- оформление и редактирование нарядов на работы;
- сохранение данных между запусками приложения в JSON-файлы.

### Ключевые каталоги

- `Productions/Domain` - доменные модели предметной области.
- `Productions/Repository` - интерфейсы репозиториев и реализации для работы с файлами и памятью.
- `Productions/Usecase` - прикладная логика для операций над сущностями.
- `Productions/*.cs` - WinForms-формы, точка входа и код пользовательского интерфейса.

## Как устроено хранение данных

При запуске `MainForm` создаются файловые репозитории, которые работают со следующими JSON-файлами в каталоге запуска приложения:

- `products.json`
- `operations.json`
- `tools.json`
- `material.json`
- `drawing.json`
- `workshop.json`
- `workorder.json`
- `tooltype.json`

Если нужного файла еще нет, соответствующий репозиторий начинает работу с пустой коллекцией.

## Запуск проекта

### Требования

- Windows
- `.NET SDK 8.0` или выше
- Visual Studio 2022 или совместимая среда разработки

### Запуск через Visual Studio

1. Откройте решение `Productions.sln`.
2. Убедитесь, что проект `Productions` выбран как `Startup Project`.
3. При необходимости восстановите NuGet-пакеты.
4. Запустите приложение через `F5` или `Ctrl+F5`.

### Запуск через командную строку

```powershell
dotnet build Productions.sln
dotnet run --project .\Productions\Productions.csproj
```

## Пользовательское руководство

### Общий принцип работы

Главное окно приложения содержит вкладки со справочниками. На каждой вкладке данные отображаются в таблице, а действия выполняются через кнопки добавления, редактирования и удаления.

### Рекомендуемый порядок заполнения

Чтобы избежать пустых зависимостей между сущностями, удобнее работать в таком порядке:

1. Добавить типы инструментов.
2. Добавить инструменты.
3. Добавить операции.
4. Добавить продукцию.
5. При необходимости добавить материалы, чертежи и цеха.
6. Создать наряды на работы.

### Работа с основными разделами

#### Типы инструментов

- Откройте вкладку типов инструментов.
- Нажмите кнопку добавления.
- Заполните данные и сохраните запись.
- Для изменения или удаления выберите строку в таблице.

#### Инструменты

- Сначала убедитесь, что создан хотя бы один тип инструмента.
- Перейдите во вкладку инструментов.
- Добавьте новый инструмент через форму ввода.
- Для изменения или удаления сначала выберите нужную строку.

#### Операции

- Перед добавлением операции должен существовать хотя бы один инструмент.
- Откройте вкладку операций.
- Создайте операцию и свяжите ее с инструментами.
- При редактировании выберите строку операции в таблице.

#### Продукция

- Перед добавлением продукции должна существовать хотя бы одна операция.
- Перейдите во вкладку продукции.
- Создайте карточку продукта и привяжите к ней операции.
- Для изменения и удаления выберите запись в таблице.

#### Материалы, чертежи и цеха

- Эти справочники ведутся независимо через отдельные вкладки.
- Для каждой сущности доступны базовые CRUD-операции: добавить, изменить, удалить.

#### Наряды на работы

- Перед созданием наряда должна существовать продукция.
- Перейдите во вкладку нарядов.
- Создайте новый наряд, выбрав необходимые связанные данные.
- Для редактирования или удаления сначала выберите нужную запись.

### Сообщения об ошибках

Приложение показывает предупреждения, если:

- не выбрана строка для редактирования или удаления;
- пользователь пытается создать зависимую сущность без предварительно заполненных справочников.
